# 🚀 SiteGen AI

**SiteGen AI** is an AI-powered website generation platform that transforms natural language prompts into modern, responsive websites. Users simply describe the website they want, and the AI generates clean, production-ready HTML, CSS, and JavaScript code in seconds.

---

## ✨ Features

- 🤖 AI-powered website generation
- 🎨 Modern and responsive UI
- 💬 Prompt-based website creation
- ⚡ Fast website generation
- 📱 Mobile-friendly designs
- 📄 Clean HTML, CSS, and JavaScript output
- 🔍 Live preview support
- 💾 Download generated website code

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Bharathkumar300704/sitegen-ai-.git
```

### Navigate to the project

```bash
cd sitegen-ai-
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
uvicorn main:app --reload
```

## 💡 How It Works

1. Enter a website description.
2. AI analyzes the prompt.
3. Generates responsive website code.
4. Preview the generated website.
5. Download and customize the generated files.
